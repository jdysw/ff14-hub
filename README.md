# FF14 Hub

把常用网站、国服活动、钓鱼日程和待办放在同一页的 FF14 工具站。

**[打开 FF14 Hub →](https://ff14.zhixia.uk/)**

打开网页即可使用，无需注册本站账号。电脑和手机浏览器都可访问；个人导航、收藏、待办和钓鱼进度默认保存在当前浏览器。

## 可以用它做什么

| 功能 | 用法 |
| --- | --- |
| 网站导航 | 按分类浏览常用 FF14 网站，收藏常用入口，也可以添加自己的链接。 |
| 全站搜索 | 一处搜索网站、鱼类、活动和设置功能，直接进入对应内容。 |
| 国服活动 | 查看进行中和即将开始的活动，打开完整日历了解时间与官方公告。 |
| 钓鱼 | 切换国服或国际服，查询鱼类、钓场、时间与天气条件，记录已钓获、收藏和提醒标记。 |
| PVP 战场 | 查看国服纷争前线、水晶冲突的地图轮换与倒计时。 |
| 我的待办 | 记下游戏计划，在首页查看和管理。 |
| 个人首页 | 在设置中调整模块顺序与显示内容，选择默认钓鱼区服。 |

## 第一次使用

1. 打开 [网站](https://ff14.zhixia.uk/)，浏览首页；点击导航项旁的星标，把常用网站加入收藏。
2. 进入 **设置 → 首页**，选择需要的模块和默认钓鱼区服。自己的链接可以在 **设置 → 个人导航** 中添加。
3. 有了个人记录后，到 **设置 → 数据管理 → 备份与恢复** 导出一份备份。换设备时可以用它恢复资料。

搜索快捷键：按 `/` 或 `Ctrl/Cmd + K` 聚焦搜索框，方向键选择结果，`Esc` 收起结果。正在输入文字时，`/` 不会打断编辑。

## 钓鱼与鱼糕进度

鱼类详情中可以查看时间、天气、前置鱼等条件，并设置钓获、收藏和提醒标记。国服与国际服的个人进度分别保存。

**预测窗口是安排日程的参考，不代表一定能钓获。** 标为候选、资料待补或来源有差异的内容，请结合详情中的条件说明和来源核对。国服活动也以官方公告为准；没有可靠时间的公告不会被当作确定日程。

已有鱼糕进度，可以选择两种方式：

- **文件导入导出**：进入 **设置 → 数据管理 → 钓鱼导入导出**，选择区服，上传鱼糕导出的 JSON 文件，核对预览后确认。也可以从这里导出鱼糕兼容进度。鱼糕文件本身不包含区服，请先确认选择正确。
- **同一浏览器内实时互通**：在 **设置 → 数据管理 → 云端同步** 中连接鱼糕。需要支持用户脚本的浏览器、脚本管理器和本站提供的互通脚本；首次同步先预览并确认差异。自动更新需要本站与鱼糕页面都保持打开，不承担跨设备同步。

安装步骤、冲突处理和恢复方法见 [鱼糕实时互通说明](docs/fishcake-realtime-sync.md)。

## 数据保存、备份与换设备

**个人数据默认只保存在当前浏览器，不会因为在另一台设备打开网站而自动出现。** 清理本站数据、使用无痕窗口或更换浏览器，都可能使原来的记录不可用。清理或换设备前，请先导出备份。

| 需求 | 入口与操作 |
| --- | --- |
| 保存一份完整备份 | **设置 → 数据管理 → 备份与恢复 → 导出全部个人数据** |
| 在新设备恢复 | 在同一入口选择个人备份文件，核对后确认恢复；恢复会替换当前浏览器的个人数据。 |
| 用自己的云存储同步 | **设置 → 数据管理 → 云端同步**，配置 WebDAV 或 S3，读取远端预览、处理冲突后再应用。 |

WebDAV/S3 需要你自己的存储服务，并允许浏览器跨域访问。云端同步由你主动发起，不会在后台自动覆盖资料；新设备需要重新填写连接配置。

个人备份不包含云存储密码或通知渠道凭证，备份文件本身包含个人资料，请妥善保存。WebDAV/S3 凭证在本机加密保存，浏览器直接连接你的存储服务。

详细配置见 [个人同步和通知说明](docs/personal-sync-and-notifications.md)。

## 提醒怎么用

在 **设置 → 通知** 中配置提醒。钓鱼页面的“提醒”标记用于选择关注的鱼，实际接收通知还需要启用相应渠道。

- **网页内提醒**：允许浏览器通知后，在网页运行期间按设置的提前量提醒。浏览器休眠或关闭网页后，不保证送达。
- **每日后台汇总**：可配置 Server 酱 Turbo 或 Resend 邮件，按设定的北京时间发送今天、明天的关注鱼窗，以及所选的活动结束前提醒。配置后关闭网页也可接收每日汇总；它不是每个鱼窗开放前的即时闹钟。

后台投递需要在服务端加密保存所选渠道的凭证。配置后请发送测试消息，并在接收端确认是否收到。具体设置与限制见 [通知说明](docs/personal-sync-and-notifications.md#通知)。

使用中遇到问题，或发现网站链接、活动时间、鱼类条件有误，可以 [提交 Issue](https://github.com/jdysw/ff14-hub/issues)。请附上操作步骤、浏览器或设备信息；钓鱼问题请注明区服与鱼名。截图中请遮住密码、密钥和个人资料。
