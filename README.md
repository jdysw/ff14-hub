# FF14 Hub

一个 FF14 导航站，也能看国服活动、查鱼窗、记待办。

**[ff14.zhixia.uk](https://ff14.zhixia.uk/)** · 打开即用，无需注册

## 功能

- 网站分类、收藏和个人链接，全站搜索网站、鱼类与活动。
- 国服活动日历，查看进行中和即将开始的活动。
- 国服 / 国际服鱼窗查询，记录钓获、收藏和提醒，支持鱼糕进度导入导出及同浏览器互通。
- 国服纷争前线、水晶冲突地图轮换与倒计时。
- Universalis 市场行情，按简体中文物品名查询单服 / 大区价格，查看 NQ/HQ 在售与近期成交。
- 个人待办，可调整首页模块的顺序和显示内容。

## 数据与提醒

个人数据保存在当前浏览器。换设备或清理浏览器前，请在 **设置 → 数据管理 → 备份与恢复** 导出备份。也可以配置自己的 WebDAV / S3，手动同步。

提醒在 **设置 → 通知** 中开启：网页内提醒需要页面运行；Server 酱 Turbo / 邮件提供每日汇总。给鱼打上“提醒”标记后，还需要配置通知渠道。

鱼窗仅供参考，候选条件和资料差异会在详情中标出；活动时间以官方公告为准。市场价格来自 Universalis 玩家上传的快照，可能有延迟，单价未含购买税费。
