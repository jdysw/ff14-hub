# 私用以太之光 · A 方向

用户选择：轻盈线条与留白。原创 SVG 将 FF14 私用以太之光的不规则蓝色晶体、斜向环架与卫星晶体简化为平面图形。

- `aetheryte.svg`：网页主标志，128 单位画布。
- `aetheryte-small.svg` / `/favicon.svg`：小尺寸专用轮廓，32 单位画布。
- PNG 图标由主 SVG 渲染，安装图标采用浅色不透明底；maskable 版本保留更大安全边距。

造型参考：[Lodestone 道具资料](https://na.finalfantasyxiv.com/lodestone/playguide/db/item/aeeb4ad3360/)、[Square Enix 私用以太之光模型](https://gb.store.square-enix-games.com/final-fantasy-xiv-miniature-aetheryte)。使用的是重新绘制的图形，不将商品照片作为网页图标。
