# FF14 Hub 国服活动管理（当前方案）

管理员现使用 **独立站点账号 + 密码 + TOTP 双因素验证**，不再由玩家设备白名单授予管理员权限。

完整的首次开通、身份验证器绑定、登录及紧急恢复说明，请参阅 [活动管理员操作指南](./calendar-admin-guide.md)。

## 与旧版设备白名单方案的关系

- 生产环境已执行过 `0017_calendar_admin.sql`；该迁移**不可重写或删除**。
- 新迁移 `0018_calendar_admin_mfa.sql` 新建独立管理员账号、会话、审计及活动覆盖表，并把既有 `curated_calendar_events` 的编辑和隐藏记录迁入新表。
- 旧表保留以供审计与应急恢复，但 `/api/v1/admin/calendar/*` 设备白名单写入入口已取消挂载；设备凭证不能再编辑站点公共日历。
- 新管理员先进入「国服活动日历 → 管理员登录」，仅首次开户使用部署既有的 `BOOTSTRAP_SECRET`，日常编辑只需账号密码与六位 TOTP。
- 网站公开活动、个人工作空间和私人钓鱼数据互不混淆。未经授权的用户不能读取管理修订记录或执行写入。

**安全提示：** 不要把初始化密钥、管理员密码、TOTP 种子或登录令牌提交到仓库、Issue、聊天或 URL。
