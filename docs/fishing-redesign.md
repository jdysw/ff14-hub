# 钓鱼重做与浏览器本地数据（2026-10-19）

## 用户端架构

普通用户直接打开网页即可保存钓获、收藏、个人导航、首页模块顺序/开关与备忘。用户端由 LocalApp 提供，不创建工作空间，不要求登录或设备令牌，不请求 /api/v1/me。个人数据保存在当前浏览器的 IndexedDB；每次修改为一个原子事务，多标签页通过 BroadcastChannel 刷新，失败不降级成假装保存的内存数据。

站长管理公共内容的认证与普通用户数据分开：站点公告、官方活动等仍由站长后台维护，普通用户只读取公开内容。原有服务器数据与 API 为兼容保留，不主动删除用户远程数据，也不把它自动复制到本机。

## 鱼糕导入导出

设置 → 鱼糕数据导入 / 导出，选择 JSON 后会预览 completed、pinned、alarmFish 的数量；文件不含区服，须确认国服或国际服。默认只合并 completed 为已钓获，空 pinned/alarmFish 不清空已有收藏与提醒。可明确选择一并合并收藏和提醒。未知数字 ID 保留，不因目录暂未收录而丢弃。

一次性本地原子合并，不受旧服务器每批 200 项限制。完整样例的 1,754 个 ID 已在本机兼容验证，文件本身不进入仓库。钓鱼进度可从网页导出为鱼糕兼容的三个数组；完整个人备份另用 ff14-hub-local v1 格式，包含两个区服的进度、导航、首页配置和备忘。完整恢复需预览并显式确认，会替换本机个人配置；旧字段修订递增，避免另一标签页的旧操作覆盖恢复结果。

个人数据由当前浏览器管理；更换域名、设备、浏览器或清理站点数据前应先导出，随后在新浏览器导入。没有隐式的跨设备云同步或服务端个人备份。

## 调研与数据来源

- [Fish Tracker](https://github.com/icykoneko/ff14-fish-tracker-app)：阅读声明式 data.js、完整鱼类指南、窗口与排序结构；使用时间/天气规则和鱼饵路径，不执行下载的 JS，不嵌入整站。
- [Teamcraft](https://github.com/ffxiv-teamcraft/ffxiv-teamcraft)：阅读 fishing-log-tracker-page-data 和 legendary-fish；补充鱼饵/钓场和明确鱼皇名单，不根据鱼名猜测分类。
- [鱼糕 V2](https://fish.ffmomola.com/ng/)：检查其公开页面与资源所呈现的鱼名/钓场筛选、鱼饵路径、鱼识前置、窗口详情和导出格式。没有复制其应用源码、私有数据库或素材。
- [国服游戏表](https://github.com/thewakingsands/ffxiv-datamining-cn)：FishParameter + SpearfishingItem 核对身份，Item/EventItem 中文名称、TerritoryType/PlaceName 钓场区域。IsHidden 会标记鱼王，不能当作未开放过滤；任务物品需要 EventItem.Singular 回退。

精确来源 SHA 在 data/fishing-sources.json 和每个快照中。Fish Tracker 与 Teamcraft 的 MIT 许可证文本保留在 third_party，游戏事实与代码许可分开说明。

## 覆盖量与准确性边界

国服目录 2,764 条：有普通钓鱼窗口规则 874 条，资料明确无时间/天气限制 359 条，规则待补或非普通鱼窗机制 1,531 条。目录包括任务等非标准笔记记录，不能作为成就所需鱼数。国际服指南/Tracker 合并目录 1,724 条：普通鱼窗规则 874 条、无时间天气限制 359 条、待补 491 条。不声称覆盖全球最新所有鱼或所有海钓/刺鱼规则。

社区规则与国服身份是两个来源，未完成逐条国服历史验证。预测仅表示时间/天气交集；鱼饵、泳饵、鱼识和任务条件仍需满足。未知规则不会伪装成全天，海钓和刺鱼不会套用普通鱼窗。首页直接显示列表和同页详情，无需二次导航；全目录先计算/筛选/排序，再限制显示数。预测放在独立 Web Worker，不堵塞搜索与页面。既有天气引擎继续使用 MIT 来源实现。

公开快照随前端部署，个人标记不再依赖生产 D1 的目录覆盖。更新来源时先核查提交，再修改 data/fishing-sources.json，运行 node scripts/refresh-fishing-catalog.mjs。脚本只下载固定提交的公开事实并生成 JSON，不访问个人文件、不上传私人进度、不写云端数据库、不启用已停用的收费 Actions。网络需既有代理时，只为当前进程配置可信代理。

## 本地复核

lint、typecheck、工作区测试、运维脚本测试、build；新增测试核对真实中文身份/鱼饵、任务鱼、Zalera 的 ET 09–14 窗口、全目录预测、未知规则不冒充全天和失败意图重试。

启动已构建应用的本地预览后运行 pnpm run e2e:local-personal（默认 http://127.0.0.1:8897）。该脚本用独立 Chromium 数据目录和生成的 1,754-ID 样本，验证真实 IndexedDB 持久化、文件合并、导出、完整恢复、导航/备忘、双标签并发和存储拒绝；断言无 Authorization 或私有 API 写请求。实际用户提供的文件另在本机隔离浏览器中验证，不写仓库或测试日志。
