# 私用以太之光：管理与个人工具升级

## 日常使用

- 首页模块自动按实际高度排布，初始内容加载后再平衡一次。之后内容刷新保持列归属；增删模块、排序、列宽变化重新计算。接近等高时保留顺序；奇数末项通栏只有在明显改善高度差时使用。DOM 始终保留用户阅读顺序。
- “今日计划”入口合并到“我的待办”。旧备忘 ID、正文、完成状态和个人备份继续有效。支持快速添加、备注、开始/截止/提醒时间、实际日期、倒计时、完成、删除和撤销。不添加日常/周常模板。
- 时间使用浏览器本机时区，活动和 PVP 使用北京时间。通知需另行启用；仅网页通知需保持网页运行。后台投递共用现有渠道和 5 分钟调度，受每日额度、重试与订阅有效期限制。后台登记未来一年内最近 30 个待办；90 天不访问订阅过期，长期待办需在到期前访问续期。
- 导航采用主分类、子分类。选中主分类才展开子分类；标签参与搜索而不重复占一条筛选栏。197 个导入条目有显式分类映射和用途说明，另有保留稳定 ID 的系统入口；同名不同功能/语言的入口不凭名称直接合并。
- 品牌名称为“私用以太之光”，图标采用用户选定 A 方向的原创 SVG：蓝色不规则晶体、金色环架、轻线与留白。32px favicon 使用简化造型；手机安装图标有独立安全边距。

## 在线管理

在设置中使用“管理员登录”，沿用现有唯一 owner 密码与 TOTP。普通个人数据仍保存在 IndexedDB / 用户自己配置的同步存储，不新增普通用户账号。

- 展示与分类：站名、公告、首页模块全局开关、默认顺序、布局策略；主/子分类增删、改名、排序、迁移。
- 网站目录：分页、搜索、编辑、主/子分类选择、批量迁移/下架/删除、标签替换、JSON 导入导出。批量请求逐条执行，失败时显示成功数量，不能视为全有或全无的事务。
- 活动：人工新增/修订/隐藏、直接删除、官方同步；开始与结束可分别为空，结束条件写入说明。完整区间才能输出 ICS。
- 回收站：删除不会只是隐藏按钮的改名。删除条目不出现在正常目录，仍可恢复；彻底删除后禁止恢复，并保留来源屏蔽标记和操作审计。内容删除属于业务永久删除，数据库审计与原始来源保留，不声称已物理擦除所有副本。同步、种子升级和重新部署均不能清除屏蔽状态。个人收藏不随公共条目删除。
- 游戏数据：PVP 轮换顺序、锚点、周期、版本；鱼类名称、饵料说明、条件说明和结构化预测规则修订。需来源 HTTPS 链接及原因，先预览再发布。历史版本可载入草稿重新发布。Web、公共鱼窗接口及在线 Android 摘要共用发布数据；Android 离线/旧缓存仍使用上次成功同步规则。
- 数据修订不会自动获得“跨源核实”或实钓标签。鱼类说明字段和预测规则分开维护；清空规则会暂停该鱼预测。原始目录保留，删除修订可回退。
- 概览显示内容数量、官方快照时间及最近手动同步结果。固定来源解析器、程序代码、数据库结构、渠道密钥及权限策略仍走代码发布流程。

## 数据升级与回滚

新库先运行 `0001_core.sql`，再运行 `0022_content_management.sql`。历史完整旧库直接应用 0022；不得重放 0001，不得清空 `d1_migrations`。0022 新增管理状态、审计、游戏数据版本及手动同步记录；只把站名仍为 `FF14 Hub` 的既有配置改成新名称，保留用户自定义站名。

发布前备份目标 D1，核对库 ID 和已应用历史迁移。先在预览验证，再进行生产迁移和部署。此迁移不删除既有业务表或个人数据。回滚程序可保留新增表，勿为回滚执行 DROP。

## 验证

- `pnpm run verify:release`：lint、类型、各包回归、真实 workerd/D1、运维测试、Web/Worker 构建和环境干跑。
- `worker/test/site-content-management.spec.ts`：鉴权、删除/同步/恢复、不可间接恢复的永久删除、版本并发与历史、在线 Widget 规则一致性、长期待办及取消后撤销。
- `apps/web/test/personal-tools.spec.tsx`：奇数布局、通栏兜底、旧数据兼容、快速添加、截止与提醒区分、提醒稳定 ID、分类映射。
- 浏览器使用隔离本地 D1、合成 owner 与只读公共快照验证。不得把测试条目、测试鱼类修订或测试管理员写入生产。
