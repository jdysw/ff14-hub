# Field Guide 首页设计

采用用户选定的第 2 张视觉稿：浅灰白页面、深灰正文、青绿色操作色、衬线区标题与无衬线业务文本。
保留现有系统站名、真实网站图标、网址、分类、活动来源提示、个人收藏、模块显隐顺序和统一详情弹层。

页面先显示常用功能。活动列表以分类、名称与起止时间、剩余时间组织；鱼窗采用三列表格式列表：鱼类、地点、剩余时间。
按用户要求不显示每条鱼窗的开放状态列，不展示进度条。顶部正在开放/即将开放数量概览保留。
首页和完整鱼窗的相对倒计时均为 `HH:MM:SS`，超过一天加天数；按真实系统时间每秒更新，零点或已过期时间不会显示负数。
“后开始”和“后结束”说明计时的目标事件，避免去掉状态列后产生歧义。

## 21:9 与详情过渡

1800px 以上启用更宽的内容区域，最大 2560px：2560×1080 使用四列目录，3440×1440 使用五列，普通桌面仍为三列、手机单列。模块表格和留白随内容区域扩展，但正文不按屏幕比例无限放大。超宽屏详情层最大 1920×1120，保留四周背景和关闭区域。

详情入场 360ms：从原模块方向小幅等比缩放/位移，内容延后 55ms 淡入，背景遮罩同步渐变。退场 140–230ms（随当前可见程度调整），从当前渲染帧连续收起，避免快速关闭时跳到完整尺寸。文本不再因横纵不同的缩放比例而变形；位移最大 64×40px，不跨越整块超宽屏。

背景滚动锁定前后保留滚动条占位；关闭恢复触发控件焦点。退出期间卸载不会再次调用旧回调。用户减少动态效果时，面板和遮罩不播放动画。

导航保持三列网站列表，手机为单列；搜索整行展示，常用分类和更多分类均可访问，原分类名称未改写或合并。
保留筛选数量、清除筛选、收藏落盘、分批展示和读取失败的恢复行为。未改动数据接口、预测算法、会话或后端。

- 修改 TS/TSX 的 ESLint 检查与 `pnpm run build:web` 通过。
- ego lite 中实测从 `00:02:41 后结束` 更新为 `00:02:40 后结束`。
