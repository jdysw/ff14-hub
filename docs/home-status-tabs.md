# 首页活动与鱼窗切换

- 活动默认“进行中活动”，包含已经开始且尚未结束的日程，包括即将结束的活动。“未来活动”显示全部已确认时间、尚未开始的日程，按开始时间排序；不把时间不明的公告归入未来活动。结束时间已到的活动不再出现在进行中列表。
- 鱼窗默认“开放中鱼窗”，仅显示当前有限时间天气窗口；原有未钓获、鱼王/鱼皇条件可以通过标签切换。“未来鱼窗”显示未来 24 小时的下一次窗口，按开始时间排序；同一条鱼当前也开放时，此页仍显示下一次的开始倒计时和起止时间。
- “关注鱼窗”取当前区服的收藏或提醒标记并集，每条鱼只出现一次。此页包含普通鱼和已钓获鱼，不套用默认稀有类型或隐藏钓获条件；时间天气不限和规则待补的关注鱼仍显示已有状态，不制造有限窗口。没有预测窗口的记录不能因此当作正在开放。
- 从关注页打开完整鱼窗会保留关注条件；从开放/未来页打开会保留对应窗口阶段。完整页面的“近期鱼窗”可返回全部近期窗口，原有“我的收藏”保留，并新增“我的关注”。
- 页签切换只筛选已加载的数据，不增加活动请求频率、重复创建预测 Worker 或修改个人标记。活动继续自动每 6 小时更新，鱼窗按现有频率重算；每次重新打开首页恢复用户要求的默认页签。
- 列表仍采用最多同时显示四行、其余内部滚动；选中状态有下划线及 aria-pressed，控件可键盘操作，空列表提供对应提示。

验证覆盖活动起止边界和自动转入进行中、未来活动含远期日程、鱼窗默认开放、未来页显示下一次时间、收藏/提醒去重及普通/已钓获鱼关注显示。浏览器活动切换验收使用本地明确标记的活动夹具，线上默认页签另行核对；个人收藏测试结束后恢复原值。
