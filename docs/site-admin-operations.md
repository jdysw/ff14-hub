# 管理员后台

在 **设置 → 管理员登录** 中，使用已有唯一 owner 的账号、密码与 TOTP 动态码登录。设置标题也保留快捷入口。刷新或退出会清除浏览器内存中的会话。

## 可在线维护的内容

- 站名、公告、首页模块开关、默认顺序和布局策略。
- 导航主/子分类与网站目录：编辑、导入导出、标签替换及批量操作。
- 国服活动：新增、修订、隐藏、删除和官方源手动同步；起止时间可分别留空，完整区间才能导出 ICS。
- 回收站：恢复已删除条目或彻底删除。彻底删除保留来源屏蔽状态和审计记录，源刷新及重新部署不会使其重新出现；不等于物理擦除全部历史副本。
- 游戏数据：PVP 轮换及鱼类说明、预测规则，填写来源和原因，预览后发布；可从历史版本载入草稿。

修改使用修订号防止覆盖并发更新。批量操作逐条执行，失败时按实际成功数量处理，不视为整体事务。规则修订不会自动获得跨来源核实或实钓标签；Android 离线缓存仍使用上次成功获取的规则。

## 认证和数据边界

只允许已激活的唯一 owner，没有网页/API 注册、首次初始化或重新绑定入口。账号恢复须在备份和审计后通过离线维护处理，不能开放临时注册接口。

密码使用随机盐、PBKDF2-SHA256 和部署密钥派生的 HMAC；TOTP 种子加密保存并防止时间步重放。随机 Bearer 会话在数据库只存摘要，有效期八小时，网页仅在内存持有。登录有服务端限流，所有后台业务操作都校验会话。

玩家个人资料在本机浏览器或用户配置的同步存储，后台不提供玩家云存储密码或个人资料浏览。数据库、Cloudflare Secrets、域名、解析器和程序代码仍通过受控工程发布修改。

`BOOTSTRAP_SECRET` 参与管理员验证、TOTP 与通知凭据加密派生。不要以替换它的方式重置管理员；丢失或随意更换可能使现有认证及密文失效。

数据库要求与恢复流程见 [迁移说明](d1-single-baseline.md) 和 [运维手册](operations-runbook.md)。
