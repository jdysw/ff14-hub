# 首页阅读与导航细化

基于 GitHub `main` 的 `9727da2`，保留现有浅色首页、模块概览与原位展开层。

本轮针对真实正式站页面观察到的导航扫描成本做局部改进：桌面搜索与分类分行，所有分类可见；手机使用有标签的原生分类选择器，避免横向截断。网站行保留真实图标、名称、简介与域名，收藏按钮去掉重复边框并保留明确的选中状态与 44px 点击区域。

正文、辅助字与操作色采用共享语义变量；不新增营销横幅、主题装饰或侧栏。活动与钓鱼继续显示已有真实数据，数量、排序、预测、覆盖层与个人数据存储不变。

筛选始终显示结果数与总数，并提供独立重置入口。初次获取目录显示加载状态；加载失败、未添加网站与无匹配结果分别提示。刷新失败保留已有目录与本机网站。搜索 `/` 快捷键在模态层中不生效，避免将焦点带出弹窗；搜索框内 Esc 清空关键词。

浏览器使用 ego lite；正式站仅用于读取设计基线，实际修改与交互验证在本地独立工作区。未包含生产部署。

- `pnpm run build:web` 通过。
- ego lite 本地交互：分类与关键词组合、空结果、清除筛选、收藏后刷新保留、Esc 清空关键词、设置往返、鱼窗详情展开关闭与模态内 `/` 不抢焦点通过。
