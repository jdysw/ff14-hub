# 首页统一搜索

顶部“全站搜索”旁的输入框统一检索网站、鱼类、活动与功能。导航站保留分类与收藏浏览，移除独立的网站关键词输入框。网站分类和收藏筛选不限制全站搜索结果。

搜索结果以正常文档流插入主要内容区顶部，推开下方内容；没有搜索弹窗、背景遮罩或独立搜索路由。设置页打开搜索不会卸载未保存的表单。点击鱼类或活动进入既有详情；点击同步、备份等设置功能时收起结果并进入对应设置。

- `/`、Ctrl/Cmd+K 聚焦顶部输入框；编辑输入、文本框、contenteditable 或打开的模态框不被 `/` 抢焦点，IME 组合期间不触发快捷键。
- 输入即更新本地结果；↓ 从输入框进入结果，↑/↓ 在结果项之间移动，Esc 收起。收起保留关键词，清空按钮清除关键词；普通 Tab 仍可访问筛选与操作。
- 结果按网站、鱼类、活动、功能分组，可切换有匹配项的类型。每组默认六项，更多结果由用户展开。
- 空输入只展示少量常用功能，不预取鱼类与活动。非空搜索按区服共享鱼类目录与公开活动读取，不把关键词发送给服务端，也不按每次按键请求接口。
- 各来源失败独立提示，已加载的网站、个人链接和功能仍可使用。公开网站目录使用首页同一份数据与重试入口。

视觉延用 Field Guide 的灰白底、墨绿强调与衬线标题。桌面输入框与工具栏同排，中小屏单独一行；结果按宽度从双列转单列，正常滚动，不限制在一屏高度。
