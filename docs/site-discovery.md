# 全站搜索、今日计划与数据诊断

全站搜索入口在页头，Ctrl/Cmd K 打开。已加载的网站、当前区服鱼类、公开活动和功能入口在本机匹配；输入关键词不会逐字请求服务器。鱼类结果携带区服和 ID 定位，活动结果定位单条记录。部分公共来源失败时保留其余结果。

今日计划按北京时间统计到当天午夜，收藏和提醒中的未钓获鱼参与计算；每次最多 50 条，超出时明确提示。计算在 Worker 中执行，保留跨日完整鱼窗，候选窗口仍须满足鱼识、鱼饵与技能等条件。个人备忘可勾选完成并持久保存，完成状态不会每天重置，可随时取消勾选。

同步诊断依次展示配置保存、远端读取、差异核对、确认应用。读取成功只证明读取和文件格式检查通过；写权限与条件写在用户确认应用时验证。404 只进入新建预览，不提前 PUT。错误不回显远端响应或凭证。备份状态只表示已触发导出，需要用户确认下载文件确实保存。

Workers Builds 使用 `pnpm run verify` 构建，主分支通过 `pnpm run release:production` 发布。发布脚本只在 Workers CI 的 main 上允许生产发布，先上传版本、确认版本 ID，再提升至 100%，使用 `--keep-vars` 保留运行时变量与密钥，并验证线上健康和构建资源。分支 Previews 使用 `wrangler.jsonc` 的 `previews` 配置，连接独立测试 D1，不配置生产路由或 Cron。GitHub Actions 不随本次变更启用。
