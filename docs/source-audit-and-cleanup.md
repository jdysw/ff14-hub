# 源码审核与架构调整

本次审核以正式运行入口、静态/动态 import、worker URL、命令入口、包 exports、真实 API 注册及测试用途共同判断。没有按“文件名像旧代码”删除文件，也没有把测试配置、离线夹具或已发布的 API 误判为无用业务。

## 调整后的结构

前端只有一个实际应用入口：`main → App → LocalApp`。owner 后台按需加载；离线数据管理随应用加载，避免首次离线打开备份功能时缺少动态分块。设置顶级分类为首页、个人导航、备忘、数据管理、通知；数据管理内部提供云端同步、钓鱼导入导出、备份与恢复。钓鱼详情的导入入口直达对应内部页面，数据格式和数据库名均不变。

`DataManagementPanel` 拥有导入/恢复的草稿、确认和异步状态；`LocalSettings` 负责设置导航、个人链接及备忘。使用隐藏面板保留切换时的已选文件和同步输入，而不是每次切换销毁草稿。同步草稿及进行中的操作也注册 PWA 更新保护。

## 发现并处理的问题

| 问题 | 证据与处理 |
| --- | --- |
| 两套前端并存 | 正式 `App` 只挂载 LocalApp，旧 AppShell/工作台/Widget/会话/导航/同步面板没有入口。移除整条旧视图链及仅针对它的验收套件。 |
| 公共目录依赖私有客户端 | LocalApp 仅为获取响应 schema 导入近 600 行旧导航客户端。schema 移入 shared 契约，前端和服务端类型不再依赖私有传输层。 |
| 当前鱼窗依赖旧宿主 | DataPort 类型和公开目录获取混在带设备凭证的 Widget 工厂中。提取最小 `lib/data-port`；目录 schema、验证和缓存由 fishing/catalog 独立负责。 |
| 倒计时牵连旧 Widget | 首页只需要一个格式化函数却导入完整活动 Widget。移入公开日历纯工具，并复用现有秒级格式化逻辑。 |
| 重复目录 UI | DirectoryBrowser 的视图未挂载，只有合并函数被使用。删除旧组件，保留并测试 `directory-links` 纯逻辑。 |
| 未注册旧后台 | calendar-admin 与 calendar-curation 只有相互引用，实际 owner API 在 admin.ts。删除旧设备白名单后台路径的源文件，不删除历史表或迁移。 |
| 双份数据库定义 | Drizzle 客户端没有调用方，schema 镜像已经无法代表新增业务表。删除镜像及 ORM 依赖，以经过 D1 测试的 SQL 迁移为唯一事实来源。 |
| 测试代码放在业务目录 | fish/adapter 只被测试导入，包含示例鱼。迁入 worker/test/fixtures，正式模块不再包含测试数据生成器。 |
| 未接入的旧同步框架 | 旧 vault/coordinator/userscript/双文件 DAV/Hub 端口只供已删除的旧页面和阶段夹具使用。删除实现、子路径 exports、对应测试与阶段 E2E 入口；保留实际在用的鱼糕格式核心。 |
| 无用依赖与样式 | 移除 react-grid-layout、Drizzle 和前端多余的直接 fish-sync 依赖；清理锁文件。按当前可产生的类名删去无引用 CSS 规则，保留动态前缀与复杂伪类。 |
| 主页面缺少渲染保护 | 旧错误边界只包住废弃宿主。为当前 App 接入安全错误视图和重试，不显示异常正文，避免整页白屏或私密输入泄露。 |
| 设备配置异步覆盖 | 原先读密文后异步计算，再无条件写回，跨页面可能覆盖新设置。统一通过 revision CAS 提交加密记录，冲突重算；通知更新只修改当前仍有效的同一订阅，不能恢复用户已停用的令牌。兼容旧无 revision 密文。 |

## 删除边界

保留全部已注册的服务端 API，包括现有设备与工作空间协议、授权、生命周期、幂等和备份。当前网页不再使用某个 API，不足以证明已有客户端不再使用。相关真实 D1、权限、迁移和同步冲突测试继续执行。

保留 SQL 历史迁移与既有数据，不 Drop 表、不清空数据库、不改变 WebDAV/S3 文件格式，不重置本机 IndexedDB。保留真实鱼类数据、计算引擎、公共目录管理、owner 密码/TOTP、当前 WebDAV/S3 和通知渠道。

历史 ADR 保留以解释协议来源。移除的是无法针对当前 UI 运行的旧阶段脚本，不是为了消除失败而跳过当前行为测试。当前个人资料和目录验收脚本已更新合并设置的选择器，单测新增统一入口、导入确认、目录合并和渲染恢复覆盖。

## 验证

执行代码引用复核、严格 TypeScript、ESLint、当前前端测试、鱼类/格式核心测试、完整 Worker/D1 测试、运维测试及构建干跑。通过 ego lite 验证统一设置、内部切换、超宽屏/手机布局与真实加密存储并发更新。

CSS 清理前后对数据管理页 165 个元素的关键计算样式逐项比较，一致；涉及动态鱼窗和管理员状态的界面另行目视检查。测试夹具与旧浏览器阶段入口不计入产品功能覆盖；保留的后端测试不减少协议断言。
