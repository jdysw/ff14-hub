# 数据来源与许可状态

根 `package.json` 仍声明 `UNLICENSED`，仓库没有为项目原创代码授予新的根许可证。仓库公开不代表全部内容获得 MIT 授权。

## 已保留的资料

- 第三方代码来源与版权文本见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) 及 `third_party/`。清理仓库不删除或改变这些许可文本。
- 鱼类上游修订在 `data/fishing-sources.json`，转换、观测和核对资料在 `data/fishing-*.json`；构建后的公开目录在 `apps/web/public/fishing/`。
- 导航目录与来源记录在 `data/navigation/`；`classification.json` 是导入时使用的人工分类映射，`import-report.json` 记录来源快照摘要。

## 尚未完成的确认

此前许可审查没有取得鱼糕观测资料、国服数据挖掘源及其衍生快照的完整再分发授权依据。这些问题不会因标注来源、公开可下载或应用代码使用 MIT 而自动解决。

Fish Tracker、Teamcraft 等应用代码的许可与游戏数据的权利范围分别处理。游戏名称、商标、素材和资料仍涉及原权利人的适用规则；不把第三方或游戏内容一并改标为本项目原创代码。

如要新增许可证或扩大再分发范围，先补齐贡献者权利确认、字段级来源与授权证明。当前没有因仓库清理而变更许可证、删除生产数据或改写 Git 历史。

鱼类资料的重建和准确性范围见 [跨来源核对](fishing-cross-source-audit.md)。
