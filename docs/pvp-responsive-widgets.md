# PVP 组件布局

PVP 组件合并展示纷争前线与水晶冲突。小、中、大是添加时的初始尺寸，同一实例拖动后按宿主报告的实际 dp 调整内容，不锁定信息模式。

## 当前尺寸规则

`PvpPresentation.density` 按以下优先级选择：

| 可用尺寸 | 密度 |
| --- | --- |
| 宽 <120dp 或高 <88dp | 极小回退 |
| 宽 ≥260dp 且高 ≥240dp | 大号排期表 |
| 宽 ≥220dp 且高 ≥120dp | 中号双栏 |
| 宽 ≥120dp 且高 ≥220dp | 中号竖排 |
| 其他 | 小号 |

系统字体超过默认 110% 时减少信息密度，不压缩文字硬塞。极小空间可能省略显示字段，完整地图名保留在读屏说明中。

Android 12+ 的普通宿主可以使用响应式尺寸映射；旧版 Android 及 Xiaomi/Redmi/POCO 优先使用传统 min/max Bundle，通过 `onAppWidgetOptionsChanged` 重绘。实际栅格、最小尺寸与拖动能力由桌面决定。

现有 Frontline/Crystalline Provider 身份保留，升级不丢失已放置的实例。它们与大号入口都显示两种模式，并按最早轮换边界安排一个重绘任务；没有 PVP 实例时不安排该任务。

## 背景与时间

所有现用布局使用不透明 XML 背景和独立填充层，日夜配色由 values/values-night 提供，触摸效果不承担背景填充。地图名称优先，前线与水晶同时使用颜色和文字区分。具体宿主限制见 [小米兼容说明](pvp-xiaomi-compatibility.md)。

共享国服规则的前线边界为北京时间 23:00，水晶冲突每小时换图。Web、公开 API 与生成的 Android 离线资产共用规则来源；服务端发布修订后，离线客户端仍可能保留旧缓存。

轮换使用非精确系统调度，省电和宿主刷新可能延迟，不能当作准点通知。规则及布局回归见 [Android 验收](mobile-widget-acceptance.md)。
