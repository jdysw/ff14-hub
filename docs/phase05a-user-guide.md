# 钓鱼手账（阶段05A）

本轮范围按用户最新要求收口为**框架与示例占位**。具体模板内容、真实数据和历史规则验证后续单独开发；不以这些内容阻塞框架交付。

先在“模块管理”安装并启用“钓鱼手账”，再从系统栏进入，或在工作台添加“鱼类窗口与进度”组件。
国服、国际服分别保存数据；已钓获、收藏、提醒偏好独立切换。提醒偏好目前不发送通知。
冲突时原选择保留，刷新后可以重新选择；网络失败不能当作保存成功。

页面显示ET、按本机时区显示的时间和候选天气窗口。未验证、不完整条件与示例数据会明确标注。
可按鱼名搜索、翻页、在当前页筛选未钓获/收藏/提醒偏好。每30秒及窗口重新获得焦点时更新。
当前仓库只提供合成示例，不能用它安排真实钓鱼。完整鱼类数据与真实历史案例仍待补充验证。

## 本地导入

先使用现有本地迁移命令：

```powershell
pnpm run db:migrate:local
node --experimental-strip-types scripts/prepare-fish-import.mjs data/fish-demo-cn.json .wrangler/fish-demo.sql
pnpm exec wrangler d1 execute DB --local --file .wrangler/fish-demo.sql
```

国际服示例为`data/fish-demo-global.json`。真实数据先转换为相同版本化JSON形状（规则版本、来源、
授权状态、验证状态、区服必填）。CLI整份校验后才生成SQL；同区服相同ID更新元数据，不删除进度。
不接受将国服记录装入国际服包；不要将未核对规则标为verified。迁移默认不灌入示例数据。

验收入口：`pnpm run e2e:phase05`。它复用现有本地浏览器编排，使用独立D1目录、随机一次性
设备凭证和合成数据，不部署或读取生产密钥。单测覆盖算法边界、API隔离与CAS、界面保存和错误态。
