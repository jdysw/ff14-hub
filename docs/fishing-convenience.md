# 钓鱼便利性第一批

## 钓获撤销

修改钓获后，列表上方提供 15 秒撤销。默认隐藏钓获的鱼消失后仍可使用。撤销创建新的补偿操作和修订，只恢复该条鱼的钓获字段；执行前重新读取，若其他标签页或鱼糕同步已修改该字段则拒绝覆盖。网络失败保留同一操作 ID 重试。收藏、提醒和其他鱼的记录不会跟随回滚。

## 首页筛选标签

首页显示可切换的“未钓获 / 含已钓获”“鱼王 / 鱼皇 / 所有鱼类”标签。区服和时间范围继续显示在原有时钟旁，避免重复。点“查看全部鱼类”打开完整目录，清除稀有类型和钓获隐藏限制；不修改默认区服或持久化个人配置。

## 单鱼提醒

鱼类列表新增“提醒”，可给这条鱼选择 5/10/15/30/60 分钟提前量并保存或取消。提前量按区服和鱼 ID 保存在本机通知配置中；未设置时沿用全局提前量。提醒标记本身使用既有 alarm 字段，因此继续参与鱼糕互通；设备提前量不传给鱼糕。

面板区分标记、网页通知授权、后台渠道连接。保存标记不会自动请求系统权限，也不声称已经启用投递。通知授权必须由用户点击“授权并启用网页通知”；后台渠道需到原通知设置配置，开发验收不会发送真实后台测试消息。网页内提示受浏览器支持、后台节流和网页打开状态限制；邮件/Server 酱仍是后台每日汇总，不是逐窗口精确推送。

社区规则没有被提升为已验证规则。用户主动关注的鱼按时间天气候选窗口提醒，正文明确保留鱼饵、鱼识和技能条件。后台每日汇总同样标注候选，避免当前社区规则因未逐条实钓而全部被过滤。无有限开窗规则、未知机制或缺少规则的鱼不生成假开窗通知；已钓获的鱼跳过提醒。已经进入提前量范围但尚未开窗时，网页提醒可以在下一次约 30 秒检查时提示，窗口标识保持稳定。

事件源暂不可用不阻断独立鱼窗计算；后台登记失败不阻断本机网页提醒，原后台计划保持不变，设置页可查看最近登记错误。既有每日汇总最多 50 条关注鱼、网页计划最多 30 个近期任务的边界保持不变。

## 通知直达

网页鱼窗通知携带区服、鱼 ID 和窗口开始时间。Service Worker 只根据校验过的值构造固定本站路径 `/?view=fish&region=cn&fish=8754&window=...`，忽略任意外部 URL。非鱼类或非法通知数据仍打开通知设置。

页面自动打开对应鱼、保留已钓获鱼的可见性并展开详情。原窗口过期或发生变化时说明原因并展示最新计算；即使首页隐藏钓鱼模块也能打开。可以返回全部目录继续浏览。没有收录的鱼显示缺失说明，而非切换到另一条同名鱼。

部署后已安装 PWA 可能需要接受“有新版本可用”提示，新的通知点击处理需等 Service Worker 更新激活；不强制覆盖用户正在编辑的草稿。

## 验证

回归覆盖钓获消失后撤销、不同修订拒绝撤销、首页筛选解除、单鱼提前量及取消、通知精确定位、候选/不限/未知规则、通知链接校验和同源路径构造。实际浏览器验证目标鱼打开、过期窗口说明、钓获撤销、提醒保存和再次读取、320px/393px 无横向溢出，测试后恢复标记和设备通知配置。未发送后台消息，未请求真实系统通知权限；实际设备收件不能用这些测试替代。
