# FF14 Hub 首页 UI 初稿

## 方案审视

保留现代简约 v2 的页面结构与配色。现有首页主要展示阶段说明与系统管理入口，日常查询需要先进入多个管理视图。新首页将搜索放在顶部，活动与捕鱼放在中部，导航放在底部；管理功能统一从固定设置入口进入。

本轮细化：

- 搜索范围明确为当前导航；连接会话后搜索个人目录，未连接时搜索只读推荐目录。收藏、分组与关键词共用现有导航控制器，结果直接显示在底部。
- 活动与捕鱼缺少配置时使用简短空态；存在已保存工作台页面时，改为展示该页面的可见实例，按已保存坐标的行、列排序。页面阅读布局采用响应式双列/单列，不复制编辑网格的固定高度与空白；编辑网格仍在设置中保留。
- 首页读取现有组件配置与模块权限，通过 WidgetHost 执行组件，不自动安装模块、创建实例或保存布局。隐藏实例不执行，停用模块继续由 Host 阻止执行。
- 首页与设置往返保留控制器、会话和布局/导航草稿；会话代际变化继续清空旧私有状态。草稿的 PWA 更新保护提升到会话层，离开编辑视图后仍然有效。
- 搜索快捷键为 `/`；输入框或可编辑区域中不拦截。提供跳过导航链接、明确焦点、最小 44px 交互区域及 reduced-motion 支持。
- 更新页面和 PWA 的浅色主题元数据，保留现有图标及系统能力。

## 验证与发布边界

- 前端 TypeScript 检查、Vite 生产构建与前端测试执行结果见本 PR。
- 原有会话与工作台测试改为先从设置进入管理功能，原行为断言保留；新增首页搜索、安全链接、个人目录、隐藏实例、模块禁用与快捷键测试。
- 当前环境访问正式站返回 403。Sites 托管的本地预览启动失败，因此没有完成 1440/390/320px 的真实浏览器视觉验收，也没有完成正式站会话与真实数据端到端验收。
- 本轮为可审阅的源码初稿，不发布、不合并、不修改正式站，也不变更版本号。浏览器视觉验收及真实环境联调完成后，再安排预览发布。
