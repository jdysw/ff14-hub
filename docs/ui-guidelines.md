# FF14 Hub UI 规范（2026-10）

## 首页结构

单页、连续内容布局，禁止通过侧边栏或底部 Tab 在首页模块之间切换：

1. **功能模块**：上方直接呈现活动、钓鱼及用户已启用的其他功能，遵守 `LocalData.configuration` 的显隐和排序。
2. **导航站**：永远接在模块下方，提供明显的网站名称、域名、搜索、分类和收藏；顶部提供站内「导航站」锚点，便于跳过内容较长的模块。

功能区和导航区只由标题、间距和细分隔线建立层级；不反复套独立大卡片、侧边栏和装饰面板。

## 完整展示原则

- **活动**：首页展示全部未结束的有效日程，不得用 `slice(0,2)` 等限制条数。时间待确认的公告与已确定日程分开理解，不伪造有效期；过期日程从首页排除。
- **钓鱼**：首页默认显示正在开放与未来 6 小时内将开放的鱼王/鱼皇；时间范围可切换为 24 小时、3 天、7 天。**首页最多显示 20 种鱼**（按鱼窗优先顺序），若范围内超过 20 种，显示明确的剩余数量和「展开完整页面」按钮；展开后完整列出该范围下的全部匹配鱼，并保留原筛选。默认隐藏已钓获鱼，玩家可取消该筛选。无固定鱼窗的“全天鱼”可在「全部鱼类」独立页访问。
- **完整目录**：钓鱼的「全部鱼类」入口直接展开覆盖层，提供完整目录和全部筛选。首页数量限制不影响鱼窗预测、搜索、已钓获记录与详情数据。
- **滚动**：内容密集的模块可以增加首页的自然高度，由整个页面滚动；模块容器本身不得设置固定高度、最大高度和内部纵向滚动。用户此前提到的“不拉长页面”主要针对无必要的描述性文案与设置表单，不应靠截断业务数据实现。
- **统一概览—详情交互**：活动日历、钓鱼与备忘都由首页模块触发展开覆盖层，而不是改变路由或切换整页；未来模块亦复用 `LocalModuleOverlay`。展开从触发模块所在位置开始，覆盖层外空白处、顶部「收起」按钮、Esc 均能关闭；离场动画朝原模块收缩。关闭保持首页滚动位置、筛选与键盘焦点。
- **无障碍**：复用原生 `dialog.showModal()`，使用 top layer、原生焦点约束，提供清晰标题和退出入口；用户启用减少动态效果时不播放过渡动画。
- **导航**：导航条目可按数量分批载入以控制一次性 DOM 数量；其筛选、可读性和收藏不受模块内容布局影响。

## 设计语言

- 现代简约、浅灰白背景、清晰的深灰字、冷蓝色操作色；禁止大面积深色侧栏与暖金装饰。
- 网站名称不应采用 10–11px 的过小字号，建议不低于 14–15px；域名使用较轻但仍易辨认的辅助字号。
- 对同类文本信息使用容易扫描的列表，而不是每条内容套一个突出边框的卡片。参考 Material Design Lists 规范。
- 去除口号式文案和重复标题，保留错误、数据来源、备份与区服选择等实际有用的提示。
- 支持键盘焦点、响应式布局与减少动画。

## 技术边界

- 当前入口是 `App.tsx` → `LocalApp`，而不是旧版 `AppShell`。
- 主样式：`apps/web/src/app/local/modern-ui.css`。
- 数据源、鱼窗算法、个人收藏和后台隐藏入口不得因改版而改变。

## 回归检查

- 活动数据量大于两条时，首页全部显示未结束日程，不包含有可靠时间的已过期活动。
- 首页初始选定未来 6 小时；切换 24 小时、3 天或 7 天时，首页展示前 20 条。点击剩余数量入口后，覆盖层展示**同一筛选范围**下的全部匹配鱼，倒计时与标记仍可用。
- 点击活动「完整日历」、钓鱼「查看完整鱼窗」、备忘「查看全部」，均展示统一样式的可关闭覆盖层；单击背景不会触发导航或其他模块；背景点击、Esc、关闭按钮均可收回。
- 收回后首页滚动位置不变，焦点回到原触发按钮；移动端覆盖层高度适应视窗，长内容仅在覆盖层中滚动。
- 不出现功能模块内部纵向滚动条；整个首页仍能直接到达下方导航。
- 移动端为自然连续的页面，不强制横向滚动功能模块，不出现横向页面溢出。
- 已启用模块顺序及隐藏/恢复后立即同步首页。
- 预览 `pnpm run build:web`、实际界面检查通过后，再考虑更新生产环境。
