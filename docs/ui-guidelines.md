# 界面规范

## 首页与详情

首页连续展示已启用的活动、钓鱼、PVP、待办模块，下方是导航站。模块尊重本机显隐和排序，桌面按实际高度排布；内容刷新不随意交换列位置，DOM 保持阅读顺序。手机端自然纵向滚动，不强制横向滚动模块。

活动和鱼窗概览最多四行可见，其余结果在列表内滚动，标题和操作区固定。可滚动列表保留键盘焦点，不通过截断业务结果限制高度。

首页鱼窗默认关注正在开放及未来 24 小时，详情提供 6/24/72/168 小时、完整鱼类目录及进度筛选。候选与缺失资料明确显示，不把预测写成必然可钓。

活动日历、鱼窗、PVP 和待办共用 `LocalModuleOverlay`，原生 dialog 提供标题、焦点约束、Esc 和关闭按钮。点击背景可收起，关闭恢复首页滚动位置和触发焦点；减少动态效果时停用过渡。

PVP 使用共享规则，前线为北京时间 23:00 轮换、水晶冲突每小时轮换，不依赖服务器逐时触发。游戏运营可能调整规则，界面不能把预测表述为官方保证。

## 导航与搜索

主分类直接展示，选中后展开子分类；标签参与搜索，不再单列筛选栏。目录保留稳定 ID，收藏不随公共目录下架而丢失个人记录。

网站图标取目标站公开 favicon，失败回退到文字，不调用第三方通用图标服务。个人网站简介可手填或提取公开网页 head，提取不覆盖人工内容。批量补全最多十条，失败保留手动编辑入口。

顶部全站搜索检索网站、鱼类、活动和功能，结果在正常文档流中展开，见 [搜索说明](unified-home-search.md)。

## 样式与无障碍

当前采用 Field Guide：浅灰白底、深灰绿文字、墨绿操作色、衬线标题，品牌使用蓝晶体与金色环架。复用当前 CSS 变量，不混回旧版侧栏或卡片样式。

入口级联顺序保持：`modern-ui.css` → `modern-content.css` → `modern-components.css` → `pvp-panel.css` → `field-guide.css` → `home-cards.css`。`css-order.spec.ts` 检查此顺序；调整前后须核对实际界面。

同类文本使用列表，减少重复标题和装饰面板。保留错误、区服、来源和备份提示。交互使用合适的原生元素，焦点清晰，文字与背景保持足够对比度。

回归至少覆盖桌面/手机无横向溢出、hidden 面板不显示、键盘搜索和滚动、弹层关闭/焦点恢复、模块显隐排序及备份兼容性。样式或 DOM 检查不冒充截图级视觉验证。
