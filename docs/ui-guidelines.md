# FF14 Hub 界面约束

适用：当前生产入口 `apps/web/src/app/App.tsx` → `LocalApp`。旧 `AppShell` 并非当前首页渲染路径。

## 界面布局

- **主屏只保留一个当前工作区**：桌面侧栏、移动底部模块切换；导航、活动、钓鱼、备忘不纵向堆叠。
- **非内容页不使用长页面**：设置的首页、导航、备忘、钓鱼数据、备份与恢复一次显示一个面板；视窗不足时仅具体面板的内容区滚动。
- **内容区允许内部滚动**：大量网站、鱼类、真实活动、用户备忘属于内容；滚动发生在相应容器内部，而不是依靠整页下拉找功能。
- **导航分类采用即时筛选**：不沿页面堆叠所有分类。搜索保留 `/` 快捷键；收藏、个人站点与推荐目录的原数据读写逻辑不变。
- **模块自定义仍然有效**：显示/隐藏、顺序、国服/国际服选项保存在本机数据模型；关闭的模块仍可在设置中启用。
- **管理员入口不外露**：复用设置标题的隐藏触发方式；已认证时才显示后台入口。

## 视觉系统

- 深海蓝应用框架 + 暖金装饰线 + 珍珠白内容面板。
- 标题只用于功能识别，禁止重复的主副标题、营销口号、占位简介、无意义英文标签与强行补充的说明段。
- 真正影响用户决策的说明必须保留，例如离线/错误、数据备份覆盖、区服不随导出文件保存等。
- 所有触控操作提供可见焦点、明确 `aria-label`、足够大的点击区域；`prefers-reduced-motion` 下不做位移动画。

## 文件归属

- `apps/web/src/app/local/LocalApp.tsx`：应用工作区结构和模块导航。
- `apps/web/src/app/local/LocalSettings.tsx`：分区设置，保留原存储逻辑。
- `apps/web/src/app/local/aether-ui.css`：新版视觉与响应式规则，加载在旧样式之后。
- `apps/web/src/app/shell/HomeOfficialEvents.tsx`：可在首页复用的真实活动摘要。

## 验收要点

1. 桌面与 390px 移动端：首页无需整页滚动即可切换全部已启用的模块。
2. 活动、钓鱼、导航条目较多时，可滚动其**内容容器**且切换按钮不会消失。
3. 设置页一屏出现分类入口和一个设置面板；模块显示/隐藏、重排、备份恢复操作保持可用。
4. 站点公告、离线更新提示出现时不应遮挡底部模块切换。
5. 页面无需服务器身份认证即可访问公开活动、目录和本机钓鱼记录。
6. 必须在可运行前端环境中执行 `pnpm --filter @ff14-hub/web typecheck`、`pnpm --filter @ff14-hub/web build`，并执行浏览器尺寸与键盘检查；静态检查不等于运行验证。
