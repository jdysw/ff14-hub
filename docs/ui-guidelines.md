# FF14 Hub UI 规范（2026-10）

## 首页信息架构

单页两层布局（不是侧边导航工作台）：

1. **功能模块**：活动、钓鱼、备忘及以后启用的新模块，在上方自适应卡片区域直接展示内容。顺序、显示/隐藏、默认区服由个人设置决定，首页有“自定义”入口。
2. **导航站**：固定在模块区域下方，搜索、分类与收藏筛选持续可见；大量站点只滚动目录内容区域。

桌面端模块尽量并列展示，视窗内能直接看到导航；手机端模块位于顶部可横向划动的同一区域，导航在其下方，不通过侧边栏或底部 Tab 切换模块。模块和目录都可在各自的内容区域滚动，避免无限纵向堆叠。

## 设计语言

- 现代简约：浅灰白背景、白色面板、深灰字体、克制的冷蓝色操作强调。
- 禁止大面积深色侧栏、暖金色装饰、游戏主题强制装饰、口号式副标题和重复解释文案。
- 功能优先：搜索框、分类、模块管理、收藏、倒计时与真实数据优先于装饰。
- 保留必要的功能/安全提示：加载、错误、数据备份、导入区服确认。
- 交互优先保证键盘焦点、清晰状态、响应式布局和减少动画设置。

## 技术边界

- 当前入口：`apps/web/src/app/App.tsx` → `LocalApp`；不要只改旧 `AppShell`。
- 样式：`apps/web/src/app/local/modern-ui.css`，由 `main.tsx` 在既有样式之后加载。
- 模块列表与顺序读取 `LocalData.configuration`，不可用写死的页面切换取代。
- 站点管理后台保留隐藏触发，不新增可见的管理员初始化入口。
- 本机数据与可用的公开 API 不应因为样式改造改变契约。

## 验收

- 桌面：模块在上、导航在下，模块切换入口和深色侧栏不存在。
- 手机：仍是同一首页，上方模块滑动，下面直接是导航，不能出现横向页面溢出。
- 个人设置：停用、重新启用与排序模块后首页立即生效；收藏与站点搜索可用。
- 月历独立内容页可以滚动；普通首页只在模块或目录内部滚动。
- `pnpm run build:web`、手动预览部署和生产冒烟正常后再发布主环境。
