# FF14 Hub UI 规范（2026-10）

## 首页结构

单页、连续内容布局，禁止通过侧边栏或底部 Tab 在首页模块之间切换：

1. **功能模块**：上方直接呈现活动、钓鱼及用户已启用的其他功能，遵守 `LocalData.configuration` 的显隐和排序。
2. **导航站**：永远接在模块下方，提供明显的网站名称、域名、搜索、分类和收藏；顶部提供站内「导航站」锚点，便于跳过内容较长的模块。

功能区和导航区只由标题、间距和细分隔线建立层级；不反复套独立大卡片、侧边栏和装饰面板。

## 完整展示原则

- **活动**：首页列表包含全部有可靠起止时间的未结束日程，同时最多显示 **4 项**，其余在列表内滚动。按临近结束、近期开始、进行中、远期排序。标题与操作区固定在列表外；不显示“其余日程／待核实公告”底部按钮。无可靠时间的公告仍可在顶部“完整日历”查看，不伪造倒计时。
- **钓鱼**：首页默认显示正在开放与未来 **24 小时**内将开放的鱼王/鱼皇；所有匹配鱼进入列表，最多四行可见，其余独立滚动。仅显示鱼名、地点和秒级剩余时间，无逐行开放状态列。顶部“全部鱼窗”展开详情，可选择 6 小时、24 小时、3 天、7 天以及完整鱼类目录。保留个人区服与过滤条件，默认隐藏已钓获鱼。
- **完整目录**：钓鱼的「全部鱼类」入口直接展开覆盖层，提供完整目录和全部筛选。首页四条概览不影响鱼窗预测、搜索、已钓获记录与详情数据，首页不重复展示完整页的搜索框、筛选表单及标记操作。
- **滚动**：活动和首页鱼窗使用四行的可视窗口，仅列表自身纵向滚动；标题、统计、列名和操作区固定。滚动边界不连带滚动页面；列表可用键盘聚焦。列表保留所有有效结果，不截断业务数据。页面其他位置仍可正常滚动至导航站。
- **统一概览—详情交互**：活动日历、钓鱼与备忘都由首页模块触发展开覆盖层，而不是改变路由或切换整页；未来模块亦复用 `LocalModuleOverlay`。展开从触发模块所在位置开始，覆盖层外空白处、顶部「收起」按钮、Esc 均能关闭；离场动画朝原模块收缩。关闭保持首页滚动位置、筛选与键盘焦点。
- **无障碍**：复用原生 `dialog.showModal()`，使用 top layer、原生焦点约束，提供清晰标题和退出入口；用户启用减少动态效果时不播放过渡动画。
- **导航**：全部分类直接显示在首页，包括手机端自动换行；不再使用“更多分类”或分类下拉框。网站条目仍可分批显示。

## 导航站站点图标与简介

- 系统推荐目录已有经过核对的 `description` 字段：首页直接复用，不重复抓取。
- 个人网址可以保存可手动编辑的短简介和同源网站图标 URL；新增字段保持可选，旧版 IndexedDB 数据及备份继续可读取。
- 图标直接读取目标网站的 `/favicon.ico`（若已成功识别到其 `<link rel="icon">` 则优先该路径），失败回退到 `apple-touch-icon.png`，最终回退名称首字，不调用第三方通用 favicon 服务。图片禁止发送 Referer，CSP 仅开放 HTTPS 图片。
- 新增网站且简介留空时尝试自动获取；个人导航设置可单条触发提取、手动编辑或批量补全每次最多 10 条。**自动提取只取网页公开 head 的描述，不使用生成式内容猜测网站用途，也不覆盖已有人工简介**。
- 服务端按需提取的公开接口应用客户端与全站限流：仅允许公网 HTTPS 网站、禁止 IP 和常见本地地址、禁止跨站重定向、严格限制读取字节与请求时长，不存储用户网址/简介。不保证所有网站都可被抓取，拒绝服务端访问时保留空简介及人工编辑入口。
- 首页网页简介最多两行，移动端可缩成一行，不能为了简介牺牲链接名称可读性。

## 设计语言

- 现代简约、浅灰白背景、清晰的深灰字、冷蓝色操作色；禁止大面积深色侧栏与暖金装饰。
- 网站名称不应采用 10–11px 的过小字号，建议不低于 14–15px；域名使用较轻但仍易辨认的辅助字号。
- 对同类文本信息使用容易扫描的列表，而不是每条内容套一个突出边框的卡片。参考 Material Design Lists 规范。
- 去除口号式文案和重复标题，保留错误、数据来源、备份与区服选择等实际有用的提示。
- 支持键盘焦点、响应式布局与减少动画。

## 技术边界

- 当前入口是 `App.tsx` → `LocalApp`，而不是旧版 `AppShell`。
- 主样式：`modern-ui.css`，最终视觉与滚动规则由其后的 `field-guide.css` 覆盖。
- 数据源、鱼窗算法、个人收藏和后台隐藏入口不得因改版而改变。

## 回归检查

- 活动同时可见最多 4 项，其他有效日程保留在滚动列表；无可靠时间的公告仅在完整日历查看，已过期日程不进入首页。
- 首页鱼窗默认未来 24 小时，最多 4 行可见，其他匹配鱼可在列表内滚动；详情可选择 6/24 小时或 3/7 天，秒级倒计时与标记可用。
- 点击活动「完整日历」、钓鱼「查看完整鱼窗」、备忘「查看全部」，均展示统一样式的可关闭覆盖层；单击背景不会触发导航或其他模块；背景点击、Esc、关闭按钮均可收回。
- 收回后首页滚动位置不变，焦点回到原触发按钮；移动端覆盖层高度适应视窗，长内容仅在覆盖层中滚动。
- 列表边界滚动不带动标题、统计与页面；列表外滚动仍可到达下方导航。全部分类均直接可见。
- 移动端为自然连续的页面，不强制横向滚动功能模块，不出现横向页面溢出。
- 已启用模块顺序及隐藏/恢复后立即同步首页。
- 预览 `pnpm run build:web`、实际界面检查通过后，再考虑更新生产环境。
