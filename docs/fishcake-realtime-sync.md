# 鱼糕实时互通

设置 → 数据管理 → 云端同步 → 鱼糕实时互通。

在支持用户脚本的浏览器安装 Tampermonkey 或 Violentmonkey，再安装本站的 `/fishcake-sync.user.js`。安装后刷新本站与鱼糕。只保留一个鱼糕页面，并在本站选择正确区服后点击“读取并预览鱼糕进度”。首次有差异时逐项选择，也可统一保留鱼糕或本站；点击“确认双向同步并启用自动更新”后生效。

互通包含已钓获、收藏、提醒三个集合，以及取消这些标记的操作。鱼糕数据不自带区服，同一浏览器的连接一次绑定一个区服和一个 Hub 域名。生产和预览不能同时绑定，切换前应先在原站点断开。

## 自动更新的范围

本站在页面打开期间约每 5 秒检查进度；鱼糕通过 Redux 订阅发布更新，并每 5 秒发布在线心跳。浏览器后台节流可能增加延迟。两边任一页面关闭、设备休眠或用户脚本不可用时，自动更新暂停；页面重新打开后可继续。不提供关闭网页后的后台同步，也不声称能在不同浏览器或设备间实时同步。现有 WebDAV/S3 个人备份仍为独立功能。

手机浏览器需实际支持用户脚本及 Web Locks。脚本不需要鱼糕账号、WebDAV 密码或站点服务端访问凭证。同步数据只经过用户脚本管理器在当前浏览器中的存储与两站页面，不发送到 Hub 服务器。

## 数据保护与恢复

- 首次连接只读取并预览；不能将“连接”当作已经完成首次同步。
- 保存共同基线，以三方比较处理新增和取消。自动处理无冲突变化；发现差异需选择时停止自动更新，等待重新预览。
- Hub 标签页用 Web Locks 串行执行。鱼糕只允许一个脚本适配器持有锁；检测到其他原生鱼糕标签页写入持久化进度时停止写入，要求关闭多余页面并刷新。
- 写入鱼糕前比较其当前进度与预览快照；写入本站前比较本地数据修订。过期命令、未确认写入、并发修改不以最后写入者覆盖。
- 两站不能组成同一个事务。鱼糕成功、本站发生并发变更时保留两边状态并暂停；重新预览后解决，不静默回滚用户的新操作。
- 本站在本机加密保存共同基线、同步状态和上次同步前的本站进度；鱼糕侧用户脚本另保留写入前进度。不写入个人备份、不包含凭证。可点“预览恢复同步前进度”，核对后再确认替换两边的三个集合。
- “断开互通”先停止本站自动更新，再释放用户脚本绑定；若脚本已卸载，本站仍保持暂停，错误信息会提示刷新/安装。

## 当前鱼糕适配证据

已审计鱼糕公开页面和运行时版本 `803987e`（当前根站）与 `9e1f21f`（旧 `/ng/` 页面）。`/ng/` 当前可能重定向至根站。脚本核对版本、模块地址和运行时能力；未列入版本不写入，需审计后更新脚本。

鱼糕 Redux 的 `completedFish` 和 `pinnedFish` 是物品 ID，`alarmFish` 是钓点鱼 ID，例如 `108:8754`，不能直接当作数字物品 ID 使用。本适配器使用鱼糕本身的钓点鱼模型转换提醒，通过原生 `fishing/importSettings` reducer 更新页面和 Redux persist；保留仍启用提醒的原钓点选择，拒绝无法转换的提醒。鱼糕旧 `userData` 的未迁移选择通过其迁移语义读取；原生 reducer 保留其他旧字段，不直接重写整份存储。

这不是鱼糕官方 API。适配器没有复制鱼糕应用源码或素材；仅根据公开数据形状、导出模块能力和运行时行为编写互操作代码。

## 验证

自动测试覆盖首次差异选择、鱼糕确认前不改本站、取消标记、区服隔离、并发拒写、离线保留与重试、来源校验、提醒双向 ID 转换、旧数据迁移和未支持提醒拒写。生成脚本由 `pnpm run generate:fishcake-script` 构建，`pnpm run check:fishcake-script` 校验发布文件与源码一致。

实际鱼糕 `803987e` 页面验证了三集合 reducer 写入及恢复；完整生成脚本也通过浏览器内提供的标准 GM API 测试桥接完成发布快照、接收命令、写入确认和恢复。预览站与真实鱼糕页面的接线测试还覆盖：首次确认、鱼糕三集合变化自动进入本站、本站取消收藏传回鱼糕、两边进度恢复及断开。两站均运行实际应用及生成脚本，测试桥接仅替代脚本管理器的 GM 存储通信，测试后进度已恢复。此测试桥接不等于用户已安装 Tampermonkey/Violentmonkey；个人浏览器仍需安装脚本并首次确认。脚本管理器真实安装及用户自选浏览器的后台节流行为需在该浏览器上确认，不以测试桥接冒充扩展安装验收。

鱼识多来源条件准确性与个人进度互通是不同能力；这次接线不会将未核对的数据条件提升为已验证，也不要求逐条实钓。
