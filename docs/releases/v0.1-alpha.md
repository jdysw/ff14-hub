# v0.1-alpha 上线记录（06G）

2026-10-19（北京时间）已部署个人使用 alpha：个人导航、模块化工作台、手工活动、导航/工作台导入导出及响应式界面。真实鱼糕双向同步、完整鱼类数据、自动推送和外部告警继续按各自集成门槛推进。界面仍保留开发阶段说明和模板占位，尚未完成面向公众的首次使用向导。

## 访问与首次使用

- 正式站：<https://ff14.zhixia.uk>
- 预览站：<https://ff14-preview.zhixia.uk>
- 正式站本机访问文件：仓库忽略目录 `.wrangler/release/access.production.json`；其中 `deviceToken` 填入网站的「会话凭证」→「设备令牌」→「保存到会话内存」，再进入「自定义工作台」。不要把整个文件导入工作台备份入口。
- `recoveryKey` 是身份恢复凭证，应私下备份；不要放进聊天、URL、版本库或公开附件。设备令牌只存页面内存，刷新后需要重新填写。
- 已启用个人导航和活动模块，并创建「起始页」与导航搜索、常用网站、近期活动三个组件；未导入具体游戏模板或演示链接。
- 此网络下命令行直连 workers.dev 超时；经系统原有本地代理完成全部线上检查。未改动系统代理、DNS 或 TUN。其他网络可达性尚未逐一验证。随后已绑定并验证自定义域名，正式域名可在本机直连；workers.dev 入口继续保留。

## 运维边界

本版不启用 Cron，不配置 VAPID 私钥，不导入未经验证的真实鱼类数据。演示与未集成功能保留标识。云端整库备份/恢复演练尚未执行，现有恢复演练仍为本地证据；手工活动增删也不等同于验证自动推送。

后续发布验收应使用只读的固定目标健康检查与现有本地 CI；需进行生产写入测试时，应采用单独授权、最小权限及自动清理机制。初始化、浏览器验证及首次使用文件均不进入版本库。
