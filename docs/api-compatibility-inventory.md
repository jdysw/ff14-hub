# FF14 Hub API 与数据兼容边界清单

更新：2026-10-24。以 `worker/api/v1/index.ts` 路由装配、`README.md` 和对应 Worker 模块为依据。**这里只列出代码是否注册，不能证明生产环境是否仍有外部客户端在调用，也不代表某张生产表为空。**

| API 路径 | 当前主要角色 | 现行前端使用情况与处置 |
| --- | --- | --- |
| `/api/v1/health`、`/api/v1/modules` | 公开状态与目录 | 保留 |
| `/api/v1/navigation`、`/api/v1/events`、`/api/v1/fish` | 公开目录、官方活动、鱼窗计算 | 当前站点/小组件仍依赖，保留 |
| `/api/v1/site` | 公开展示设置 | 当前站点使用，保留 |
| `/api/v1/admin` | 唯一 owner 站点管理会话与编辑 | 当前管理员使用，保留；不可增设匿名注册 |
| `/api/v1/local-notifications` | 匿名设备独立订阅令牌、后台投递计划 | 当前个人提醒使用，保留；密文与本机偏好分离 |
| `/api/v1/widgets` | Android 原生桌面组件公开数据 | `apps/android` 使用，保留 |
| `/api/v1/identity` | 早期工作空间初始化、设备配对及恢复 | 已注册；现行 Web 主入口不再需要普通设备登录，但外部历史客户端状态**未知** |
| `/api/v1/me`（含 `workbench`、`modules`、`navigation`、`events`、`sync` 等） | 设备认证后工作空间、布局、个性化模块、备份与同步 | 服务端测试覆盖且路径仍注册；用户历史数据及外部使用量**未知** |
| `/api/v1/__test__` | 仅测试环境使用的自检 | 默认配置关闭，确保生产不可达 |

## 数据所有权（不能混淆）

- **当前用户个人资料**：浏览器 IndexedDB 的个人链接、备忘、钓鱼标记；由用户 WebDAV/S3 直连同步，不上传本站 Worker 作为主存储。
- **设备配置及凭证**：本机独立加密记录；普通个人备份不包含凭证。
- **公开目录与管理数据**：D1 的公共目录、活动官方快照、站点配置和管理员编辑审计。
- **当前后台通知**：D1 独立订阅表中的密文投递渠道、任务与限额；不是旧设备工作空间令牌。
- **早期工作空间数据**：迁移及 API 保留的设备、模块状态、导航、活动、工作台和同步流水，不应与 IndexedDB 同步模型混合或者直接删除。

## 兼容 API 安全退场判定

必须全部满足以下前置条件后，才考虑弃用 `/identity` 与 `/me`：

1. 明确列出外部使用者，包括旧移动/油猴脚本、历史 PWA 客户端、已部署实例及第三方集成；
2. 对生产 D1 **只读统计**兼容表的实际数据量、最近访问/操作审计和最后同步水位，不查询明文凭证；
3. 设计可逆的数据导出和迁移机制，验证旧备份在现行前端能够恢复；
4. 给出公告、弃用时间、版本化 API 响应和回滚窗口；
5. 先移除可证明无人使用的视图适配层，最后才评估停止写入/下线 API；**历史迁移不删，未经备份不 DROP 表**。

本次 PR #78 不删除任何兼容端点、不改数据库结构、不清空用户数据。若需要真正下线，另行代码评审及生产数据核实后执行。
